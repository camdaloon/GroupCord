# GroupCord Roadmap

This roadmap outlines the planned development of GroupCord.

---

# ✅ v0.1.0 — Foundation

- [x] Discord Bot
- [x] GroupMe Bot
- [x] Two-way message bridge
- [x] Express webhook server
- [x] SQLite database
- [x] Slash commands
- [x] Multi-server support

---

# ✅ v0.2.0 — Native Discord Experience

- [x] Automatic Discord webhooks
- [x] Native GroupMe usernames
- [x] Native GroupMe profile pictures
- [x] Automatic webhook recreation
- [x] Health checks
- [x] Better setup flow

---

# ✅ v0.3.0 — Rich Messages

- [x] Images both directions
- [x] Replies both directions
- [x] Discord edit notifications
- [x] Discord delete notifications
- [x] Status command
- [x] Unicode emoji support
- [x] Multiple bridges
- [x] Attachment support
